场景分层

Scenario layering · 按“在哪儿用、谁在场、自主程度”归类

同一套系统不会只在一种环境里使用。把使用情形按地点环境、参与人员、系统自主程度分成四层，后面分别规定每层的条件和风险，避免“一套条件套所有场景”。

A · 临床医疗层

监督最强的医疗环境

手术室、康复训练室。有医师、治疗师在场，系统以调试和康复训练为主，参数由专业人员掌握。

典型场景：植入 / 开机调试、闭环康复训练
B · 居家日常层

佩戴者独立使用

家庭客厅、卧室。患者或增强用户独立完成生活动作，家属可旁观，系统处于自主使用状态，远程随访兜底。

典型场景：穿衣、取物、日常移动
C · 现场协同层

任务导向的人机协同

控制室或作业现场。操作员就地或远程操控机械臂、外骨骼，替代人进入噪声、辐射等危险环境完成作业。

典型场景：远程巡检、危险环境替代作业
D · 应急兜底层

跨环境的安全状态

不专属于某个地点。任何一层出现异常时，系统转入待机、降级或紧急断开，任务暂停，只保证人身与设备安全。

典型场景：故障保护、急断、状态保持

运行设计条件

Operational design conditions · 范围、系统状态、人员状态

3.1 运行设计范围

系统被允许正常工作的边界；超出边界应降级或暂停，不硬撑运行。

条件类别允许范围通俗说明
环境温度体表 / 穿戴段 10–35 ℃；植入段按体温区间过冷过热都可能影响电极与佩戴者感受，超出即提示停用
湿度相对湿度 30%–75%，无凝露潮湿会影响电极接触与电气安全
电磁环境日常民用电磁环境；强干扰下进入降级强电磁干扰可能让信号失真，此时只保留保守功能
姿态与动作坐姿、站姿及限定动作范围内；跌倒、剧烈晃动触发保护动作不在预期姿态内时，先保持姿态再判断
任务与负荷单次训练 / 作业不超过设定时长；动作幅度、力矩按个体限位防止过度疲劳和超关节范围用力
网络条件本地闭环不依赖联网；云端同步仅在联网时进行断网时本地闭环照常工作，数据稍后再同步
佩戴时长单次连续使用 ≤ 2 h；康复训练按疗程上限超时提醒休息，避免长时间佩戴不适

3.2 系统状态

系统任一时刻处于一种工作状态，状态按条件切换；下表列出各状态的含义与进出条件。

系统状态白话含义进入条件转出条件
自检上电后逐项检查电极、电池、传感器和链路开机通过 → 校准；异常 → 待机并告警
校准采集基线信号，标定意图映射和个人限位自检通过、佩戴者配合标定完成 → 康复 / 增强；失败 → 重试或待机
康复训练治疗师在场监督下辅助训练治疗师在岗、患者状态达标训练结束 → 待机；异常 → 降级 / 急断
自主增强佩戴者独立使用，系统跟随意图动作标定完成、经监督者授权出现风险 → 待机；结束 → 待机
安全待机低功耗监测，保持当前安全姿态，不主动输出动作任何异常或主动暂停条件恢复并确认后回到对应模式
紧急断开切断机器通路，回到原生神经状态按下急断按钮或出现严重风险需人工复位后重新自检
故障降级部分功能受限运行，如减弱助力、只保留反馈单点故障但尚未失控故障排除后恢复正常状态

3.3 人员状态

系统能不能进入某个模式，不只看设备，还要看人的状态是否满足前提。

  • 佩戴者：意识清醒、能配合指令；没有明显疲劳、疼痛或眩晕；肢体残存能力符合当前模式要求；知情同意有效。状态下降时，不进入高自主模式。
  • 治疗师 / 监督员：在岗且具备相应资质；能看到解码置信度与告警；拥有模式切换和参数调整权限。离岗时，系统不得停留在无人监督的高助力模式。
  • 运维人员：设备巡检、校准、算法更新由授权人员执行；普通佩戴者不接触底层参数。

典型场景详述

Selected scenario · 卒中后上肢闭环康复（康复训练室）

场景档案

  • 人物：62 岁卒中后左侧上肢偏瘫患者，Fugl-Meyer 评分 28 分；康复治疗师在场。
  • 地点：医院康复科训练室，安静、照明充足，座椅与辅具齐全。
  • 目标：完成一次闭环训练，改善上肢抓握能力，记录训练数据，过程中不造成二次伤害。
  • 对应条件：处于康复训练模式；佩戴者状态达标；治疗师在岗；各项参数在运行设计范围内。

训练过程（按时间顺序）

1
准备与自检：患者落座，上肢佩戴表面肌电 + 惯性单元，肘关节处接电刺激反馈。系统上电自检电极阻抗、电量、传感器与链路，通过后进入校准。
2
基线校准：患者按指令做几次小幅动作，系统采集残存肌电，标定意图映射和个人关节限位；治疗师确认参数后再开始训练。
3
闭环训练：患者试图抓握水杯 → 系统采集残存肌电 → 解码出“伸手抓握”意图和置信度 → 外骨骼辅助抬手 → 指尖压力传感器把接触感回传，让患者“感觉”到杯子。
4
监督调整：治疗师看到置信度 0.82，适当减小助力，让患者多发力；若患者出现疲劳或疼痛上升，就降载或暂停。
5
收尾归档：训练结束系统回到安全待机，生成本次训练曲线与评分；数据脱敏后同步云端，设备由治疗师复位。

本场景的条件对照

条件维度本场景满足情况
运行设计范围训练室温湿度日常水平；单次训练在时长上限内；动作幅度与力矩按患者个人限位执行。
系统状态自检 → 校准 → 康复训练 → 安全待机，状态切换均有对应条件确认。
人员状态患者清醒、能配合；治疗师在岗并掌握参数与模式权限。

典型场景安全风险分析

Risk scenario list · 诱因、后果、等级与处置

编号风险场景诱因可能后果等级处置与对应安全需求
RSK-01信号受出汗、伪迹干扰，低置信度时仍驱动动作电极出汗、肌电混杂误动作、拉伤高置信度 < 0.6 时禁止使能执行器（SAF-REQ-01）
RSK-02助力超过肘关节活动限位未绑定个人限位、不同患者参数混用关节拉伤高动作范围按个体限位硬约束，超限自动限幅（SAF-REQ-02）
RSK-03电刺激幅度或脉宽超限刺激参数误调皮肤刺痛、神经不适中刺激参数设硬件级上限，超限自动切断（SAF-REQ-04）
RSK-04治疗师短暂离岗，系统仍保持高助力模式切换缺少确认环节无人监督下误动作中离岗 / 模式切换须治疗师确认并记录（SAF-REQ-05）
RSK-05电极脱落或信号中断未被识别电极松动、导联断线误判意图中阻抗与断线监测，异常进入安全待机（SAF-REQ-03）
RSK-06患者疲劳、疼痛上升仍继续训练主观状态未纳入判断二次伤害中疲劳 / 疼痛输入触发降载或暂停；告警双通道提醒（SAF-REQ-08）
RSK-07训练原始数据被直接上传本地脱敏失效隐私泄露中原始数据不出本地，云端仅接收脱敏特征（SAF-REQ-06）
RSK-08训练中断电，外骨骼突然失去支撑执行器依赖持续通电保持姿态肢体失支撑、部件坠落中断电时机械抱闸，锁止在安全姿态（SAF-REQ-07）

等级说明：高表示可能造成身体伤害，需硬件级防护；中表示可能造成不适或流程风险，靠监测、降级与流程确认控制。
